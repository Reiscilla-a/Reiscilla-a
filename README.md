### About

I hold a degree in **Systems Analysis and Development** and work as a full stack software engineer focused on **applied AI**. My work spans from interface design to back-end architecture, through the data layer and the integration of language models, always with attention to usability, performance and maintainable code.

### What I do

- **Full Stack:** web applications and APIs with Python/Django on the back end and React on the front end.
- **Applied AI:** integrating LLMs, chatbots and machine learning models into business workflows.
- **Data & BI:** SQL modeling and querying, data processing with Pandas and Spark, dashboards in Power BI.
- **Mobile:** native Android apps with Kotlin and Java.
- **Product & UX:** prototyping in Figma and building accessible, responsive interfaces.
